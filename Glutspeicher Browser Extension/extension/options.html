Glutspeicher

The address of the Glutspeicher web interface. Without a scheme, http:// is used.

Security

The Glutspeicher server has no login and no TLS of its own. All entries, including the passwords, are loaded from it every time the popup opens. Use the server only in a trusted network, or put it behind a reverse proxy with HTTPS and enter its https:// address here.

The extension stores only this address. Passwords are kept in memory while the popup is open and are never written to the browser's storage.
